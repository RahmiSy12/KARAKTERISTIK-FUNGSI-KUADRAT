Materi Pembelajaran

Bentuk Umum Fungsi Kuadrat

Fungsi kuadrat adalah fungsi polinomial dengan pangkat tertinggi variabelnya adalah dua.

f(x) = ax² + bx + c

Syarat mutlak: Nilai a ≠ 0. Jika a = 0, maka persamaannya menjadi linier, bukan kuadrat.

  • x = variabel
  • a = koefisien x²
  • b = koefisien x
  • c = konstanta

Langkah-langkah Menganalisis

  1. Perhatikan nilai 'a': Menentukan apakah parabola terbuka ke atas atau ke bawah.
  2. Hitung Diskriminan (D): D = b² - 4ac. Menentukan jumlah titik potong dengan sumbu X.
  3. Tentukan Sumbu Simetri: x = -b / 2a. Garis tengah yang membelah parabola.
  4. Tentukan Titik Puncak: (x, y) dimana y = -D / 4a. Nilai optimum grafik.

Penjelasan Sederhana

Efek Nilai a

Jika a > 0 (positif), grafik tersenyum 🙂 (terbuka ke atas, punya nilai minimum).

Jika a < 0 (negatif), grafik sedih ☹️ (terbuka ke bawah, punya nilai maksimum).

Efek Diskriminan (D)

D > 0: Memotong sumbu x di 2 titik.

D = 0: Menyinggung sumbu x (1 titik).

D < 0: Mengambang / tidak menyentuh sumbu x.

Mini Simulasi Grafik

Geser nilai a, b, dan c untuk melihat perubahan grafik secara langsung!

Diskriminan (D): 0
Terbuka ke: Atas

Contoh Soal

Contoh 1: Analisis Dasar

Soal: Tentukan karakteristik grafik dari fungsi f(x) = x² - 4x + 3.

Jawab:
a = 1, b = -4, c = 3.
1. Karena a > 0 (1 > 0), maka grafik terbuka ke atas.
2. D = b² - 4ac = (-4)² - 4(1)(3) = 16 - 12 = 4.
Karena D > 0, grafik memotong sumbu X di 2 titik.

Contoh 2: Sumbu Simetri

Soal: Tentukan sumbu simetri dari grafik f(x) = -2x² + 8x - 5.

Jawab:
a = -2, b = 8.
Rumus sumbu simetri: x = -b / (2a)
x = -8 / (2(-2)) = -8 / -4 = 2.
Jadi, sumbu simetrinya adalah garis x = 2.

Contoh 3: Titik Puncak

Soal: Tentukan koordinat titik puncak parabola f(x) = x² - 2x - 8.

Jawab:
a = 1, b = -2, c = -8.
x = -b/2a = -(-2) / 2(1) = 2/2 = 1.
Substitusi x=1 ke fungsi:
y = (1)² - 2(1) - 8 = 1 - 2 - 8 = -9.
Titik puncak adalah (1, -9).
